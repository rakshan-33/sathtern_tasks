### 1. BankSphere

BankSphere is a web-based banking application developed to provide users with a simple and user-friendly banking experience.

* User registration and authentication
* Banking account management
* Transaction-related functionality
* User-friendly interface
* Secure backend API integration

* Node.js
* Express.js
* MongoDB
* REST API
